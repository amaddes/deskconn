# RDP-подобное приложение удалённого управления (Lazarus / Free Pascal)

Два независимых GUI-приложения на LCL (Win32):

- **rdp_client.exe** — запускается на управляемом компьютере. Слушает TCP-порт,
  аутентифицирует администратора, транслирует экран и принимает команды ввода.
- **rdp_admin.exe** — запускается у администратора. Подключается к клиенту,
  отображает удалённый экран, отправляет мышь/клавиатуру.

Оба проекта лежат в одной папке (`rdp_client.lpi` / `rdp_admin.lpi`), используют
общие модули из `common/`.

## Сборка

Требуется Lazarus (проверено на 4.8 / FPC 3.2.2), widgetset Win32.

```
lazbuild rdp_client.lpi
lazbuild rdp_admin.lpi
```

Оба `.exe` собираются в `bin\`. Промежуточные файлы сборки — в `lib\rdp_client\`
и `lib\rdp_admin\` (можно удалить, будут пересозданы).

Проекты также открываются в IDE Lazarus обычным способом (Файл → Открыть проект).

## Запуск

### rdp_client.exe (на управляемом компьютере)

Запускается **от имени администратора** (в exe встроен манифест
`requireAdministrator` — Windows покажет запрос UAC при запуске). Это нужно для
надёжной работы захвата экрана, `SendInput` и добавления записи автозапуска в
реестр.

При старте открывается окно с:

- полем **Порт** (по умолчанию `5555`);
- автоматически сгенерированным **паролем** вида `482913KQ` (6 цифр + 2 буквы,
  без похожих на цифры букв O/I) и кнопкой «Сгенерировать заново»;
- кнопкой **Старт/Стоп** — запускает/останавливает прослушивание порта;
- индикатором состояния (красный/зелёный кружок) и журналом подключений;
- чекбоксами «Запускать при старте Windows» и «Сворачивать в трей».

Пароль нужно передать администратору (вместе с IP-адресом и портом) любым
доверенным каналом — по сети в открытом виде он не передаётся, участвует только
его SHA-256-хэш в связке с одноразовой солью.

Лог событий дублируется в `%APPDATA%\RDPClient\log.txt`.

### rdp_admin.exe (у администратора)

Запускается от обычного пользователя (повышенные права не требуются). В верхней
панели вводятся:

- **IP** и **Порт** управляемого компьютера;
- **Пароль**, полученный от владельца rdp_client;
- чекбокс «Запомнить подключение» — сохраняет IP/порт/пароль в
  `%APPDATA%\RDPAdmin\last.ini` и подставляет их при следующем запуске;
- чекбокс «Только просмотр» — полностью отключает отправку мыши/клавиатуры на
  клиент (можно смотреть, не управляя).

После нажатия «Подключиться» и успешной аутентификации в основной области
появляется удалённый экран. Управление:

- **мышь** — движение/клики/колесо передаются на клиент один в один (координаты
  пересчитываются с учётом масштаба и смещения виртуального экрана);
- **клавиатура** — форма перехватывает `KeyDown`/`KeyUp` целиком (`KeyPreview`),
  так что фокус на конкретном дочернем контроле не важен;
- **F11** — полноэкранный режим;
- меню **Вид → Масштаб** — «По размеру окна» (сохраняет пропорции, letterbox),
  «100%» (пиксель в пиксель, с обрезкой по видимой области) или «Свободный»
  (растянуть на всё окно, без сохранения пропорций);
- меню **Действия → Отправить Ctrl+Alt+Del** — просит клиента вызвать `SendSAS`
  (см. «Известные ограничения» ниже);
- строка статуса внизу — FPS, битрейт, разрешение удалённого экрана, задержка
  (по последнему PING/PONG).

## Протокол (кратко)

Общий модуль `common/rdp_protocol.pas`. Кадр пакета: `[Size:uint32][Type:byte][Payload]`,
всё little-endian. Рукопожатие: `HELLO` (magic `RDP1` + версия) → `SALT` (8 байт) →
`AUTH_RESP` (SHA-256(пароль+соль)) → `AUTH_OK`/`AUTH_FAIL`. Один активный слот —
остальным подключениям отправляется `BUSY`. Кодек кадра выбирается клиентом
автоматически (RAW/RLE/zlib, наименьший по размеру), кроме первого (всегда
полноэкранного) кадра сессии — он всегда идёт как RAW, чтобы у админа сразу
появилась картинка без задержки на сжатие.

Байт версии в `HELLO` зарезервирован под будущее шифрование канала — протокол
разрабатывался так, чтобы это можно было добавить без изменения формата пакета.

## Известные ограничения

- **Шифрования канала нет.** Передаётся только SHA-256-хэш пароля с одноразовой
  солью (пароль как таковой по сети не идёт), но сам экран и команды ввода
  передаются в открытом виде. Не предназначено для использования вне доверенной
  сети/VPN.
- **Одно подключение единовременно.** Пока активна сессия, остальные попытки
  подключения сразу получают `BUSY` и закрываются.
- **Ctrl+Alt+Del не гарантирован.** Реальная secure attention sequence
  перехватывается на уровне ОС и не может быть синтезирована через `SendInput` —
  клиент вызывает `SendSAS` из `sas.dll`, что срабатывает только при включённой
  политике `SoftwareSASGeneration` или наличии прав/политик, разрешающих её. Если
  `sas.dll`/политика недоступны, клиент пишет об этом в лог и ничего не делает
  (без ложного "успеха").
- **Смена разрешения экрана клиента посреди сессии не поддерживается** —
  offscreen-битмап админа создаётся под размер первого кадра и не меняется
  динамически. Для применения нового разрешения нужно переподключиться.
- **KEY_CHAR не используется UI-слоем.** Протокол и клиентская обработка unicode-
  символов реализованы и покрыты тестами, но `rdp_admin` сейчас отправляет ввод
  клавиатуры только как `KEY_DOWN`/`KEY_UP` по виртуальным кодам (что уже
  корректно печатает текст с учётом раскладки на стороне клиента) — это сделано
  осознанно, чтобы не дублировать один и тот же символ по двум разным путям.
- Только IPv4/TCP, порт по умолчанию `5555`.
- Проверено на Windows 10/11 x86, широкий диапазон разрешений (в том числе выше
  1920×1080, включая мульти-монитор) — в остальном ориентировано на разрешения
  из ТЗ (до 4K).

## Как отключить автозапуск

В `rdp_client.exe` снять галочку «Запускать при старте Windows» — приложение
само удалит запись `RDPClient` из
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`. Вручную это можно
проверить/поправить через `regedit` по тому же пути.

## Структура проекта

```
rdp_client.lpi / .lpr        - проект клиента (со встроенным манифестом requireAdministrator)
rdp_admin.lpi / .lpr         - проект админа
common/
  rdp_protocol.pas           - типы пакетов, LE-сериализация, работа с TStream
  rdp_crypto.pas             - SHA-256, генерация соли/пароля
  rdp_codec.pas               - RLE и zlib (чистый Pascal, без внешних DLL)
  rdp_winapi.pas              - захват экрана, SendInput, композиция BGRA в HDC
client/
  main_client.pas / .lfm     - UI клиента
  server_threads.pas         - сервер на fcl-net, рукопожатие, сессия, отправка кадров
  screen_capture.pas         - TScreenCapturer (захват + построчный CRC32-дифф)
admin/
  main_admin.pas / .lfm      - UI админа
  frame_receiver.pas         - подключение, рукопожатие, приём кадров, offscreen-битмап
  input_sender.pas           - преобразование событий мыши/клавиатуры в команды протокола
bin/                          - собранные .exe (после lazbuild)
```
